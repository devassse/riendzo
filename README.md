# Riendzo
Assistente de viagens

O Riendzo pode tornar-se uma plataforma digital de referência para descobrir, compreender, explorar e viver Moçambique, reunindo informação histórica, cultura, música, gastronomia, turismo, serviços públicos, entretenimento e, como camada inteligente e monetizável, o Riendzo AI.
Abaixo está uma documentação geral que podemos usar como Documento Base / Visão Funcional da Plataforma Riendzo. Ela servirá depois como fundamento para desenharmos o esboço completo da aplicação, arquitetura de informação, wireframes e, posteriormente, o desenvolvimento.

# RIENDZO - Assistente de Viagens e Plataforma Digital para Descobrir Moçambique

Riendzo é uma plataforma digital inteligente dedicada à descoberta de Moçambique.
A plataforma pretende conectar pessoas aos:
•	lugares; 
•	povos; 
•	histórias; 
•	línguas; 
•	artistas; 
•	músicas; 
•	sabores; 
•	tradições; 
•	eventos; 
•	serviços; 
•	experiências; 
•	oportunidades de viagem. 

O Riendzo combina conteúdo, descoberta, informação prática, turismo e inteligência artificial numa única experiência digital.

Riendzo — Descubra Moçambique. Viva a jornada.
